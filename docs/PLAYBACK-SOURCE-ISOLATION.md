# Playback source isolation

A native-browser reproduction confirmed that the main player and a Studio preview could play simultaneously. The same song at different positions can then sound doubled or muddy. This is a confirmed playback defect, not proof that every reported noise has this cause.

The player now pauses other active media when a song or preview starts, including previews removed from the page by navigation. Other LAE-MUSIC tabs on the same origin yield playback through BroadcastChannel or a storage-event fallback. Focus messages contain only a random owner identifier and timestamp. Positions, queues and chosen volume are preserved. Muted decorative videos do not interrupt music. Advertisement completion retains its existing queue transition; a deliberately interrupted ad remains paused.

Maximum native output now reserves approximately 1.4 dB of headroom: slider values through 80% retain their original output, while the upper range rises gently to native volume 0.85. Both sliders still span 0–100%, and saved native-volume preferences remain compatible. Mute/recovery and old full-volume preferences respect the ceiling. No equalizer, gain boost, resampling or re-encoding was added. Publishing, storage and provider integrations are unchanged. The public-shell cache advances from v22 to v23; encrypted offline music is retained.

Verification uses synthetic local audio, not paid generation. The native browser test covers main/Studio/voice previews, detached previews and ads, completed ad transitions, pending-stream cancellation, another tab and the no-BroadcastChannel fallback at 393/1440px. Player/offline unit tests cover source/position/volume preservation, the output ceiling and old preferences, and ad-transition state. Existing continuous-playback and encrypted-offline browser journeys are also checked.

A read-only check of the existing published track 23 returned a complete 5,805,849-byte stereo MP3 (48 kHz, approximately 194 kbit/s). HTTP range bytes matched its full download and FFmpeg decoded it without errors. EBU R128 analysis measured −13.2 LUFS integrated loudness and a +0.4 dB reconstructed true peak; maximum native volume 0.85 leaves about 1 dB of margin for this sample. This does not establish the peak level of every song or guarantee distortion-free physical speakers. No provider request, play-count POST, customer-credit charge, storage write or production-data edit was made. This checks delivery integrity, not subjective clarity on a physical phone. The specifically affected song and device still need confirmation to determine whether any separate issue remains.
