## Shared name-matching correction

The supplied short research name exposed substring false positives inside ordinary
words such as “remain.” The shared registry/output guard now matches complete normalized
Unicode name tokens across string values rather than substrings of JSON text. It still
rejects actual names across casing, punctuation, full-width forms and embedded newlines.
String values are inspected before JSON escaping, so a newline cannot hide a reference.
No provider, billing, credit, financial, storage or voice-training behavior changed.
