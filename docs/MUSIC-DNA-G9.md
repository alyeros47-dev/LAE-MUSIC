# G9 — Ghanaian Gospel Praise

Instruction Package 10 adds five selectable profiles beneath the nonselectable
**Ghanaian Gospel Praise** heading, retaining exact supplied names and descriptions.
The library contains 40 styles across G1–G5 and G7–G9. G6 remains pending.

| ID | Name | BPM | Core identity |
| --- | --- | --- | --- |
| G9-01 | Covenant Celebration | 100–124 | Flowing Ghanaian contemporary praise, melodic highlife bass passing notes, clean interlocking guitars and rich choir |
| G9-02 | Royal Praise Assembly | 108–132 | Energetic Ghanaian live praise, synchronized deep bass, rhythmic organ and powerful congregational responses |
| G9-03 | Glory Rising Live | 92–118 | Expansive live Gospel, atmospheric keys, grand piano, cinematic strings and gradual climactic development |
| G9-04 | Highlife Thanksgiving | 110–136 | Flowing highlife guitar patterns, bouncy melodic bass, syncopated traditional percussion and an extended celebratory ending |
| G9-05 | Breakthrough Praise | 115–140 | Fast Ghanaian praise, rhythmic lead, punchy bass, rolling toms and a drum-and-bass dance break |

Each profile retains the approved mood, rhythm, drums, bass, keyboards, guitars,
additional instruments, melodies, arrangement, lyrics and permitted variation directions.
The production guidance preserves Ghanaian highlife/live-Gospel identity rather than
replacing it with generic Nigerian Afrobeats or Western Gospel. Highlife Thanksgiving
explicitly keeps its guitar-and-bass identity. Mood is internal; voice and language remain
independent and no gender is assigned to profile delivery. Research references stay
private and are excluded from public metadata and provider instructions.

The existing language registry supports English, Pidgin, Yoruba, Igbo, Hausa, French
and combinations. **Twi is not currently selectable or verified.** The supplied phrase
“including Twi when supported” does not activate a new provider capability in this
catalogue-only batch. Profiles never force Twi or invent unsupported translations;
future Twi support needs a shared language addition and focused integration/linguistic
verification. Existing supported languages work with all five musical profiles.
