# G7 — Gospel Soul & Inspirational Ballads

Instruction Package 8 adds five individually selectable styles under the nonselectable
**Gospel Soul & Inspirational Ballads** heading, using the exact supplied short customer
descriptions. This batch implements G7 only. G6 has not been supplied and remains pending;
the library contains 30 styles across G1, G2, G3, G4, G5 and G7.

| ID | Name | BPM | Core identity |

Each profile retains its own mood, energy, rhythm, drums, bass, keyboards, guitars,
additional instruments, melody, arrangement, lyrical themes and mixing instructions.
Approved variation directions introduce fresh phrases, voicings, instrumental entrances
and narrative expression without changing musical family. Gender-neutral profiles use
independent voice and language selections. Internal research references are excluded
from public metadata and provider instructions. No independent mood selector is added.

`npm run test:dna -- --groups G7` runs 14 focused G7 tests plus 7 CI-routing checks.
Coverage includes exact names/descriptions/tempos, selectable styles under nonselectable
headings, private research boundaries, five distinct instrumental/arrangement identities,
fixed atmosphere, voice/language combinations, bounded variation and stable retries.
Actual lyrics-handler tests use mocked provider responses and verify one credit
reservation/completion per success. Existing G1–G5 profile definitions and shared engine,
credit, voice and financial code are unchanged. Their comprehensive suites and unrelated
platform/database/browser tests are not repeated.

No paid provider calls or real audio tests were performed. Text contracts do not certify
