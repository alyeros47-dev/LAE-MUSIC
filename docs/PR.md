LAE-MUSIC currently uses several disconnected page styles and recreates playback on navigation. This draft adds a shared dark interface with a persistent real-source player and connected discovery, listener, artist, studio, partner, account and administrator screens while preserving the Node/PostgreSQL/R2 backend and legacy compatibility paths.

The change also adds owner-scoped generation retry keys, atomic lyrics-credit and gift operations, controlled upload URLs and format checks, upload quota serialization, free product-sale affiliate reporting, additive checksummed migrations, balanced append-only finance records, and withdrawal reservations/reviews with a separate 3% fee. Unsupported checkout, webhooks and payouts remain unavailable. No production data was accessed or reset; no Render deployment or production merge was performed.

Validation: `npm test` passes with 52 new behavioral/contract cases, 25 existing mocked Sonic cases, 31 Sonic static invariants and the existing integrity checks. [CI run 40184247862](https://github.com/alyeros47-dev/LAE-MUSIC/actions/runs/40184247862) also passed desktop/mobile browser journeys, actual HTTP checks, and nine checks on a disposable PostgreSQL 16 service covering fresh initialization, migration replay, concurrent gifts/credits/withdrawals/studio requests, protected reporting and restart preservation. Live storage/music/payment providers remain unverified. The dependency lockfile was captured from that CI installation.

This is not launch-ready. Read `docs/RELEASE.md` for the completed scope and remaining provider/accounting/visual/security gates, `docs/AUDIT.md` for commercial contradictions, and `docs/DEPLOYMENT.md` for staging/migration/rollback instructions. In particular, real payment settlement, automatic royalty calculation from funded revenue, bank payouts, generated-audio publication, historical balance reconciliation and unresolved legacy upload entitlements still require implementation or verification before release.
