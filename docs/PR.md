LAE-MUSIC had disconnected page styles and recreated playback on navigation. This draft adds a shared premium dark interface, persistent real-source player and connected discovery, listener, artist, studio, partner, account and admin workspaces while preserving the existing Node/PostgreSQL/R2 architecture and legacy compatibility routes.

Completed connected features include durable private studio-release copying, leased retries, owner previews and explicit publication; notification outbox delivery; revision-protected playlist management; stable filtered discovery pagination; atomic generation/lyrics/gift operations; guarded uploads and annual quotas; free affiliate registration with approved product-sale commissions; and protected reporting, content controls and withdrawals with the existing 3% fee.

The purchase/accounting milestone adds immutable server-priced orders, artist review/history/cancellation, active and future renewal terms, provider-neutral raw-byte verification plus independent payment lookup, atomic verified subscription/studio-credit fulfillment, pending commission journals, auditable receipts/review events and admin reconciliation. Database constraints protect journal uniqueness and entitlement ownership. No provider adapter is configured in production: checkout, public payment webhooks, commission clearance and bank payouts remain disabled. No real payment success is simulated. Production records were not accessed or reset; no Render deployment or production merge was performed.

Validation: local `npm test` passes 72 behavioral/contract cases, 25 existing mocked Sonic cases, 31 source invariants and integrity checks. [CI run 40192948981](https://github.com/alyeros47-dev/LAE-MUSIC/actions/runs/40192948981) passes actual HTTP checks, desktop/tablet/mobile browser journeys and 27 checks against disposable PostgreSQL 16, including verified-fixture purchases, concurrency, renewals, commissions, purchased generation credits/refunds, rollback, migration replay and restart preservation. The run also verifies final database constraints and current-state order retries. Purchase screenshots were inspected at all three sizes. All provider/payment/media test services are isolated fixtures, not real integrations.

This is not launch-ready.
