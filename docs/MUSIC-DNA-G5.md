# G5 — Indigenous Yoruba Gospel

Instruction Package 6 adds five individually selectable styles beneath the
nonselectable **Indigenous Yoruba Gospel** heading. Each has a short public description.
The catalogue now contains 25 supplied styles across G1–G5; other groups remain pending.

| ID | Name | BPM | Core identity |
| --- | --- | --- | --- |
| G5-01 | Heritage Worship | 72–96 | Reflective storytelling worship, soft talking drums, flowing bass, warm organ and acoustic guitar |
| G5-02 | Yoruba Praise Procession | 112–138 | Communal percussion-led dance pulse, talking drum, hand drums, shekere and bouncy bass |
| G5-03 | Gospel Juju Celebration | 108–136 | Prominent interlocking guitars, conversational talking drums, rolling melodic bass and extended live Juju interplay |
| G5-04 | Wisdom and Grace | 68–92 | Acoustic Gospel soul, expressive piano, understated bass, gentle hand drums and thoughtful mature imagery |
| G5-05 | Heritage Praise Revival | 105–132 | Traditional praise groove, steady dance bass, syncopated communal percussion, brass and group-response harmonies |

Profiles retain the approved moods, drum patterns, bass movement, keyboards, guitars,
other instruments, melodic character, arrangements and lyrical structures. Bounded
variation choices introduce new phrasing, harmony, instrumental transitions and lyrical
imagery while retaining each core identity. Gender-neutral profiles support independently
selected voices and languages: Yoruba instrumentation never forces Yoruba lyrics.
Research references remain internal and excluded from public and provider projections.
Juju instructions explicitly preserve live guitars, talking drums and melodic bass rather
than replacing them with generic electronic Afrobeats. No new mood selector is added.

Run `npm run test:dna -- --groups G5`. Fourteen G5 tests cover loading and public selection,
exact names/tempos, nonselectable headings, private research references, distinct core
instruments, full prompt construction, voice/language independence, bounded variation,
stable retries, fixed mood and the actual existing lyrics handler with mocked provider
replies and one credit reservation/completion per success. Seven CI-routing checks also
run. G1–G4 profile definitions and shared runtime/financial code are unchanged; their
full suites and unrelated platform/database/browser tests are not repeated.

No paid provider calls, real audio verification, production changes, merge or deployment
are part of this batch. Audio quality, linguistic accuracy and cultural fidelity still
need authorized provider/listening review during final integration. Next package:
G6 — Indigenous Igbo Gospel, pending the supplied specification.
