## Language limitations

The shared registry currently supports English, Nigerian Pidgin, Yoruba, Igbo, Hausa,
French and their supported combinations. **Twi, Ga, Ewe and a distinct Ghanaian Pidgin
option are not currently selectable or verified.** Existing Nigerian Pidgin (`pcm`) is
not relabeled as Ghanaian Pidgin. Profiles never force Twi/Ghanaian Pidgin or invent
unsupported translations. These requested language additions remain pending a shared
language integration and focused linguistic/provider verification; this profile-only
batch does not claim them as active capabilities.
